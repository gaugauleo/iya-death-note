
## ① 制作サイトのタイトル

**嫌がらせDEATH NOTE**

## ② 制作サイトの説明

あの「DEATH NOTE」をモチーフにしたメモ帳アプリ。  
名前・日付・嫌因（嫌がらせ）を記入することで、対象者にささやかな不幸をもたらします。

## ③ 工夫した点・こだわった点

DEATH NOTEの不気味な世界観を意識し、背景やノートのデザインにこだわりました。  
（なんだか最近、画像生成の能力ばかり向上している気がします...）

名前・日付・嫌因が、手書きのように左から右へ順に表示されたり、全ての文字が現れた段階で赤く光るモーションなども取り入れました。

背景画像とは別に右ページのみの画像を別で用意し、記入された文字とともに破り捨てられるモーションを入れるのがとても面倒くさかったですが、面白かったです。

## ④ 難しかった点・次回トライしたいこと

JavaScriptの配列とlocalStorageを使った、データの保存・ページ管理が難しかったです。

1人以上の記入があれば次のページへ進めるだけでなく、前のページに戻った際、空きがあればそこに新しい記入を追加できるようにする処理に苦戦しました。

## ⑤ 備考・感想

今まで習ったことを全て取り入れたメモ帳アプリを作りたい！ 
と考えて制作したテーマでしたが、モーションや演出にこだわりすぎてlocalStorageの勉強であることを忘れかけました... 楽しかったです！

今回は綿密にAIと相談し、細かなところまで決定した上で仕様書を作成して制作に進みました。

以前よりも圧倒的に進めやすかったし、後から追加する機能がない分、コードがすっきりしました。

**感想：難しい〜！！**
